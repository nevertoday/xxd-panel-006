# XXD Panel 006 · 小主体纸感艺术书封生成核心

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、构图、配色、留白关系和文案。

最终只生成当前已经锁定的**变化设计画框**：在上下双联中位于下方，在左右双联中位于右侧，在纯设计版和每张壁纸中铺满整张画布。设计画框内部不得再次出现摄影面板、分界线、边框、设备样机或预留摄影区域。

## 0. 不可改变的美学动机

每个变化画框必须同时成立：

**当前照片中特定的主体或不可拆分关系 → 至少三个身份、动作、功能或情绪线索 → 高度提炼为一个小而集中的可辨认插画单元，约占设计画框 10%–20% → 其余约 80%–90% 由粗糙白纸、暖白纸或源图相容的浅色纸面主导 → 纤细、略不稳定的手绘线只提示关键结构 → 少量完整、不透明、克制的丙烯平涂色块负责建立主体 → 从源图提取并压缩为不超过四种主要颜色 → 只以极少线条或一个克制色面暗示环境 → 文字通过大留白与小插画形成艺术书封式平衡。**

安静、童趣与诗意来自极端删减、小主体、大留白和真实身份线索，不来自笑脸、星星、太阳、爱心、吉祥物或装饰涂鸦。若换一张无关照片后，小插画轮廓、关键色块、留白关系和文案仍几乎不用改变，成品失败。

## 1. 先锁定源图事实

在内部判断但不输出分析：

1. 找出唯一主要主体，或确实不可拆分的核心关系。
2. 锁定至少三个源图专属线索，覆盖身份、动作、功能或情绪；可来自轮廓、姿态、朝向、比例、材质、颜色、开口、连接、遮挡、负形或关系距离。
3. 判断哪些复杂细节可以删除，哪些最少边缘与色块必须留下才能一眼识别。
4. 锁定小插画单元在当前画幅中的面积约 10%–20%，以及与源图姿态和文案相符的安静偏心位置。
5. 锁定 80%–90% 粗糙浅色纸面的色温、纸纹和呼吸区域。
6. 锁定纤细略不稳定线条的必要位置，以及少量完整丙烯平涂块各自承担的主体结构。
7. 从源图提取并压缩为不超过四种主要颜色，明确每种颜色的识别或结构职责。
8. 如需文字，锁定它与小主体形成构图对重的位置、层级和自然断行。

不得虚构人物经历、地点、事件、所有权、情绪或象征。地点、年份、编号只有用户明确提供或证据可靠时才能进入文字。

## 2. 小而集中的高识别主体

- 把主要主体或不可拆分关系提炼成一个紧凑插画单元，默认约占设计画框 10%–20%；不得因为画布变宽或变高就把主体无理由放大。
- 人物保留姿态、朝向、服装大形与关系距离；动物保留身体节奏与头部方向；植物保留生长手势；建筑保留天际线和关键开口；器物与交通工具保留功能轮廓、负形与朝向；自然场景保留一处源图专属地形或空间关系。
- 删除复杂写实细节，只保留少量决定性边缘、连接和色面。缩略图下也必须一眼认出主题。
- 辅助形体只能帮助识别主体或极简暗示环境，不得成为第二焦点。

## 3. 大留白是主要空间材料

- 保持约 80%–90% 的粗糙白纸、暖白纸或浅色纸面。留白不是等待填满的空洞，而是画面的尺度、安静和出版物气质。
- 小主体采用克制的非对称位置，可位于偏下、偏上、偏侧或靠近边缘，但必须与姿态、动作、阅读方向和文字形成明确平衡。
- 背景只允许极少线条或一个克制色面暗示地面、远景、围合、方向或气氛；不得重建完整场景。
- 不使用边框、栏目、背景图案、散落图标、重复符号、装饰性网格或填充留白的随机笔迹。

## 4. 纤细略不稳定线条与完整丙烯色块

- 线条只负责提示结构、边界、连接、纹理和识别；保持纤细、手绘、轻微不稳定，但不能变成抖动噪线。
- 少量不透明丙烯平涂色块负责建立主体的大形。色块清楚、完整、克制，保留手工涂抹沉积和轻微不规则边缘。
- 线条与色块分工明确：线条提示结构，色块构成主体。不得退化成纯线稿，也不得把整个纸面画满。
- 保留纸张颗粒和细微人为误差。禁止彩铅、蜡笔、油画棒、粉彩、水彩晕染、墨水洗染、厚重油画、写实体积、光滑数字插画和 3D。

## 5. 不超过四种源图颜色

- 从源图最具身份感的颜色中提取并压缩，纸面底色之外最多保留四种主要颜色。
- 每种颜色都必须服务于身份、材质、开口、服装、面部、标识、地形或功能点，不得作为无意义装饰。
- 色块鲜明、完整、克制；只要识别仍然成立，就优先使用更少颜色。
- 不使用彩虹色盘、透明渐变、灰脏混色、荧光光效、企业品牌套色、统一米灰滤镜或照片式复杂光影。

## 6. 006 专属文字形态

文字是**通过大留白与小插画建立对重的疏朗书封排版**，不是标题墙、UI 标签、数据面板或后贴的广告图层。

### 文案

- 自动文案从主体身份、可见动作、功能、关系、已知地点或当前画面的安静意涵中提炼一个简短标题、主题词、对象名称或短句。
- 默认一个标题；只有确有信息价值时增加零至两条极短辅助文字。地点、年份、编号只有用户提供或可靠建立时使用。
- 文案应与当前主体高度绑定，避免万能励志词、空泛诗句、虚构故事和为了像出版物而编造的档案信息。
- 用户最终成稿逐字保留；用户给出方向或可编辑草稿时只在授权范围内精炼。

### 字体导演

- **角色：**与小插画互相制衡、赋予纸面编辑节奏的一条疏朗书封线索。
- **气质：**安静、轻松、童趣但不幼稚、诗意、松弛、克制而高级。
- **字形：**一个简洁手工标题或低调书籍字体，最多两条更小辅助文字；不同文字系统保持各自自然比例。
- **位置：**放在小插画上方、下方或侧面的留白中，形成明确对重，不拥挤主体，不遮挡身份线索。
- **材料：**轻微不完美的干墨、不透明印刷或细腻凸版质感；不使用蜡笔字、发光、金属、玻璃或巨型商业展示字。
- **本地化字形：**中文、日文、韩文、阿拉伯文与拉丁文字保持真实结构、标点、间距、连写和语义断行，不把拉丁排版规则强套给其他文字系统。

摄影面板中绝不出现文字。无字模式中，变化画框也不得出现任何字母、汉字、数字或伪文字。

## 7. 当前模式与壁纸

调用方会在本提示词后附上已经解析完成的唯一当前模式、准确尺寸、源图可见性和锁定文字。只执行附加块中的当前值，不要自行选择模式。

- 双联设计只生成变化画框本身；摄影面板由外部独立准备和精确拼合。
- 纯设计版与壁纸不显示源照片、分界线或摄影预留区。
- 每张壁纸都为目标宽高比重新组织小主体、纸面留白和文字对重。系统 UI 区域保持低信息，不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸始终同时使用原照片和同一张已批准定调图：原照片锁定身份与内容，定调图只锁定主体比例、留白比例、细线性格、丙烯块面逻辑、四色情况、纸张质感、安静气质与文字系统。不得机械裁切或顺序垫图。

## 8. 生成前检查

1. 主体通过至少三个源图专属线索保持一眼可辨认。
2. 小插画单元约占设计画框 10%–20%，位置集中而有意图；没有无理由放大。
3. 粗糙白纸或浅色纸面约占 80%–90%，留白平衡、安静且没有被装饰填满。
4. 纤细略不稳定线只提示必要结构，没有变成纯线稿或噪线。
5. 少量完整不透明的丙烯平涂块真正建立主体，并保留纸纹、涂抹沉积和轻微不规则边缘。
6. 纸面之外不超过四种源图主要颜色，每种颜色都有身份或结构职责。
7. 没有彩铅、蜡笔、粉彩、水彩晕染、复杂写实、厚重油画、光滑数字插画或 3D。
8. 文字准确、自然、符合目标语言，并通过留白与小主体形成书封式对重；无字模式绝无伪文字。
9. 当前模式、尺寸、源图可见性、壁纸安全区和文字设置全部服从附加块。
10. 最终画面没有拼贴总览、Logo、水印、UI、样机、第二焦点或无关装饰。
